A local library for research papers

Less filing.
More reading.

Identify PDFs, correct their metadata, and give them useful names. Bring ADS papers and references from other fields into one library.

Get ADSfolioRead the guide →
01

Find the paper

Use ADS, Crossref, or DataCite. Choose the lookup order, or add your own references when a service has no match.

02

Keep your edits

Preserve metadata and file history. Preview renames and reconcile files that changed outside the application.

03

Work locally

Your catalog stays on your computer. Browse and edit without an ADS account. Online lookups contact the selected providers.

macOS with Homebrew

After the first stable release and Homebrew tap publication:

brew install --cask ysBach/adsfolio/adsfolio

From source

git clone https://github.com/ysBach/adsfolio.git
cd adsfolio
uv sync --all-extras
uv run adsfolio-gui

Desktop builds are currently unsigned. See the guide for OS requirements and installation limits.
