From PDF folders to a searchable library

  1. Choose Add PDF Folder on the welcome page.
  2. Choose Include Subfolders if your papers use nested folders.
  3. Run Identify. Review matches and papers that need attention.
  4. Preview Rename, then apply only the changes you want.

Saved results reduce repeated lookups. Identification time depends on PDF text, cache coverage, provider limits, and your connection.

Everyday workflows

Write, file, and present your research

BibTeX

Keep a .bib for your paper

Add the papers you cite to an ADS library, then export BibTeX for LaTeX or Overleaf. A watcher can keep the file current while you write.

Watch

Rename new papers automatically

Watch a folder. Each new PDF gets publication details and a filename from your template.

CV

Make your CV from ADS

Build your publication list in LaTeX, HTML, Markdown, or plain text. Choose how to highlight your name and how each entry looks.

git clone https://github.com/ysBach/adsfolio.git
cd adsfolio
uv sync --all-extras
uv run adsfolio-gui
